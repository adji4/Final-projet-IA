# 📝 Mini Application ToDo

Une application simple de gestion de tâches construite avec **React**.

## 🚀 Fonctionnalités
- Ajouter une tâche
- Marquer comme terminée
- Supprimer une tâche
- Interface claire et responsive

## ⚙️ Technologies
- React
- Tailwind CSS (ou CSS classique)
- GitHub Pages pour le déploiement

## ▶️ Lancer le projet
```bash
npm install
npm start
