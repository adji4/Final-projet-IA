# Spécification du projet ToDo App

## Objectif
Créer une mini application permettant de gérer une liste de tâches (ToDo).

## Description
- L’utilisateur peut ajouter, cocher ou supprimer une tâche.
- Les tâches sont gérées avec un state React local (`useState`).

## Technologies
- React
- HTML5 / CSS3
- GitHub Pages pour le déploiement
